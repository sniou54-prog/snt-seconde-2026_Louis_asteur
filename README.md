# 💻 Cours de SNT — Seconde (2026-2027)

Bienvenue sur l'espace de cours de **Sciences Numériques et Technologie**. Vous trouverez ici les supports de cours, les activités et les scripts Python classés par thème.

## 🐍 Fil rouge : Programmation Python
- [ ] **00. Bases de Python** (`00-python-bases/`) : variables, conditions (`if`), boucles (`for`/`while`), fonctions et listes.

## 📚 Les 7 thèmes du programme
- [ ] **Thème 1 — Internet** (`01-internet/`) : protocoles IP/TCP, routage, DNS, réseaux physiques.
- [ ] **Thème 2 — Le Web** (`02-le-web/`) : HTML/CSS, URL, requêtes HTTP, moteurs de recherche.
- [ ] **Thème 3 — Les réseaux sociaux** (`03-les-reseaux-sociaux/`) : graphes, bulles de filtres, identité numérique.
- [ ] **Thème 4 — Données structurées et traitement** (`04-donnees-structurees/`) : format CSV, traitement de tables en Python.
- [ ] **Thème 5 — Localisation, cartographie et mobilité** (`05-localisation-cartographie/`) : GPS, trames NMEA, calcul d'itinéraire.
- [ ] **Thème 6 — Informatique embarquée et objets connectés** (`06-informatique-embarquee-iot/`) : capteurs, actionneurs, IHM.
- [ ] **Thème 7 — La photographie numérique** (`07-photographie-numerique/`) : capteurs, pixels RVB, traitement d'images en Python.
